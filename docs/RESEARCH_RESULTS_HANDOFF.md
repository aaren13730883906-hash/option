回测结果不进入 GitHub。完整结果保存在项目根目录的 `research/`，需要和
`data/` 一起单独迁移。

- 文件数：`1011`
- 总大小：约 `76.8 MiB`
- CSV：`979`

- 其余为 Markdown、日志或其他复盘附件

## 结果内容

完整目录包含以下类型：

- 各版本主策略的交易明细、资金曲线和摘要；
- 科创板和创业板双标的回测结果；
- DTE、成交量、IV、止盈、止损和容量敏感性分析；
- `09:45 Put` 反转增强及其保守版结果；

- Monte Carlo、回撤和交易贡献分析；
- HTML、CSV 和 Markdown 复盘材料。

## Git 状态

历史上有 26 个结果文件曾被 Git 跟踪。它们已从 Git 索引中解除跟踪，保留在旧
电脑的本地 `research/` 目录中。后续提交不会把 `research/` 上传到 GitHub。

## 迁移方法

从旧电脑复制整个目录：

```text
research/
```

复制后比较文件数量、总大小和校验和。不要只复制几个摘要文件，否则交易明细、
资金曲线和 HTML 复盘之间可能无法对应。

新电脑如果只需要先验证环境，可以优先复制：

- `full_confirm_*`
- `put_reversal_0945_conservative20_*`
- `putrev_selection_capacity_aware_*`
- `backtest_v12_*`
- `backtest_v11_*`
- `backtest_v10_*`
- `qmt_*`

最终恢复时仍应复制完整 `research/`。

## 可复现条件

结果依赖以下外部内容：

- `data/` 中的本地期权、ETF 和分钟数据；
- 外部 ETF SQLite；
- 外部 ETF 1 分钟归档；
- 运行脚本时的参数；
- Python 和第三方依赖版本。

只复制结果文件无法重新生成结果。完整迁移必须同时保留结果、输入数据、脚本和
参数文档。
